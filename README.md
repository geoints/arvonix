# Arvonix — Digital Solutions

Статический адаптивный сайт Arvonix на HTML, CSS и Vanilla JavaScript.

## Структура

- `index.html` — секции сайта, услуги, кейс Brivora, цены, FAQ и контакты.
- `styles.css` — адаптивный дизайн и фирменная палитра.
- `script.js` — мобильная навигация, FAQ, анимации появления и год в футере.
- `assets/logo.svg` — векторная монограмма.
- `assets/favicon.svg` — favicon.

## Запуск локально

Откройте `index.html` в браузере. Для локального сервера можно использовать:

```bash
python3 -m http.server 8000
```

Затем откройте http://localhost:8000.
